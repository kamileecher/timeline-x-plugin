# Source and asset checks

Use this reference when web research will supply product claims, a visual
reference, or media for a Timeline X project. A selected external connection's
current schema determines what can be requested; another product's browser
formats, screenshot flags, download actions, or scripted page API are not a
Timeline X contract.

## Collect only what the brief requires

Keep a compact research receipt: source page, observation date, extracted fact,
supporting section, candidate direct-media URL, and uncertainty. Read the exact
detail page for a version, limitation, price, or platform claim. A search result,
homepage slogan, or dated release announcement alone may not establish present
behavior. Distinguish page content from an inference made for the creative brief.

For brand assets, identify the actual product/logo file, dimensions, transparency,
and intended use when exposed. Inspect chosen pixels before deciding that an
asset matches the requested identity. Retain attribution and any visible usage
conditions; finding a public URL does not establish redistribution rights.

## Diagnose incomplete output

- Empty extraction can mean login, consent, an unloaded app shell, unsupported
  format, anti-bot rejection, or inaccessible content. Preserve the real remote
  error and check only the bounded schema-supported remedy that fits it.
- A supported screenshot can establish visible appearance while cleaned text
  establishes readable content. Neither proves content outside the captured
  region. Do not claim full-page coverage from a viewport screenshot.
- A dynamic-page wait or scroll is useful only when the connection advertises
  it and observed loading requires it. Do not repeatedly request arbitrary waits
  or run remote JavaScript solely because a foreign guide showed an example.
- If authentication or user action is required, let the user complete it through
  the selected connection. Never ask for a password/token in chat or write it to
  a research receipt.

## Import with a concrete destination

Choose an exact media URL and reuse an existing Library item when its source and
content match. Confirm kind, resolution/duration, and final Library id after
`import_media_url`. A screenshot URL may expire; report an inaccessible result
rather than silently importing the webpage HTML instead. `import_media` is for
an already readable authorized local file.

Read-only research does not authorize imports or Timeline placement. When import
is requested, state the imported asset ids and retained source attribution;
place only the assets and range the user authorized.
