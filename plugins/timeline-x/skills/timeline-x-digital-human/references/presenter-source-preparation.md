# Presenter source preparation

Read this only for an authorized portrait, source Video or existing speech
driving a selected external avatar tool. The actual external schema determines
which source forms and limits are supported.

Choose a source with the intended subject visible, unobstructed facial features
and enough framing for the output. Do not fabricate missing readiness metadata
or treat a generated concept as a consented real-person identity. If the tool
requires a still and the source is Video, prepare a separate representative
Image through supported media tools only within the requested scope; never
pass a Video id as a portrait or claim hidden conversion.

For audio-driven presentation, inspect the actual Audio and duration. Existing
approved speech should not be synthesized again solely to satisfy a text-based
workflow. Resolve background music or competing speakers according to the
external capability. Do not promise automatic separation or clone the source
speaker without the separate consented configuration workflow.

For text-driven presentation, preserve the approved wording, punctuation and
order. Split only at supported meaningful segment boundaries, record the
original order and verify every returned segment once. Avoid using a provider's
old limit to truncate the script. A portrait upload or source approval does not
authorize an additional paid avatar generation or Timeline placement by itself.

Preserve the source background unless the user asks otherwise. Ask for alpha
output only if the selected tool advertises it. A successful job does not prove
transparent pixels, preserved HDR, frame rate or codec. Inspect edges and
framing against the actual edit, and verify the result's media properties when
delivery needs those guarantees.

Before placement, check the real face, gaze, mouth motion, complete spoken
content and aspect ratio. Keep source media and completed output recoverable;
retry only the failed segment through the service's advertised operations.
Report partial delivery explicitly rather than claiming the complete presenter
video from one successful segment.
